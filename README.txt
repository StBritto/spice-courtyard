THE SPICE COURTYARD — GITHUB PAGES PACKAGE

1. Create a GitHub repository named: spice-courtyard
2. Extract this ZIP.
3. Upload index.html and style.css directly into the repository root (do not upload the outer spice-courtyard folder).
4. Commit the files.
5. GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
6. Select main and /(root), then Save.
7. Expected URL for the StBritto account: https://stbritto.github.io/spice-courtyard/

This is a fictional restaurant demo created for RJ Digital Solutions.
